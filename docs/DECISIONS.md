# Decisions

One line per decision, with the reason. Newest at the bottom.

- Project folder is `~/Desktop/starligh-fishing-club` (the existing folder, missing a "t"); kept as-is because work is scoped to the current directory. Package and repo name use `starlight-fishing-club`.
- GitHub CLI (`gh`) is not installed, so no remote was created; manual push commands are in the README.
- Toolchain: Phaser 3.90.0, zod 4, Vite 8, Vitest 5, TypeScript 7 (current stable releases at build time).
- Text uses a bitmap font baked at boot from Pixelify Sans (alpha thresholded at 11px, aligned to the font's 91.5-unit pixel grid), because canvas text anti-aliases and looks blurry at 180x320.
- On touch devices the internal resolution grows on the free axis (up to 1.6x) to fill the phone; desktop keeps a fixed 180x320 letterbox. Layout is anchor based (`core/layout.ts`).
- Drifting parallax layers use two wrapping images instead of Phaser TileSprite, because TileSprite resamples non power-of-two textures and blurs pixels.
- Time-of-day changes dissolve with a 4x4 Bayer dither (16 steps over 8 s) instead of alpha fades, so the palette stays exact.
- The catch popup sells on any tap outside its buttons (one-tap loop); "Keep" stores the fish in the creel (inventory, capped by `storageCap`). Kept fish sell later at current prices.
- Fishing save slice is v2 (creel items with size); v1 (creel as id list) migrates automatically.
- Vitest runs in one thread with `isolate: false` because worker start-up is very slow in the build sandbox; the tests are pure and share no globals.
- Debug panel is plain DOM so it can use real inputs and copyable output; it is only mounted in dev builds or with `?debug=1`.
- Gates (typecheck, tests, build) run on a mirror of the project in the session scratchpad with its own `npm install`, because the Desktop folder is iCloud-synced on a 99%-full disk and evicted files block reads inside the sandbox. Each phase commit is exported with `git checkout-index` and gated before committing.
- Journal learns about first catches by annotating `catch.flags.new` in its `catchLanded` listener; the popup reads the flag. No feature imports another.
- Pacing is checked with a goal-directed player model (saves for the next water or crew slot, buys small upgrades under 20% of that goal). A purely greedy "cheapest first" model delayed the first water to 38 min and does not match how people play.
- Tuned: Cork Grip base cost 12 -> 20, River Charts 900 -> 1100, Hire Help 1600 -> 1800 to hit the pacing targets.
- Offline coins are the exact expected value of the simulated rolls (no luck either way); journal counts use largest-remainder rounding so they sum to the roll count. Rounding catches first and pricing them biased short absences upward (one lucky legendary).
- Offline time and the live tick share one path: any wall-clock gap over 5 s triggers catch-up, so closing the tab, a background tab, laptop sleep, and the debug fast-forward behave the same.
- Audio placeholders are soft synthesized pentatonic tones instead of pure silence (`AUDIO.placeholder = 'synth'`, switch to `'silent'` in `src/config/audio.ts`), so the game can be judged by ear before real files exist. Nothing plays before a user gesture.
- Content packs can declare `requires` (feature ids). Feature-dependent content lives in its own pack so removing a feature never breaks boot.
- Daily gift has no streak, so skipping days never costs anything (no-punishment pillar).
- The game fills the whole screen on every device (replaces the touch-only fill and desktop letterbox). Zoom is the largest whole number of device pixels per game pixel that still leaves 180x320 (portrait) or 320x240 (landscape); the internal size is rounded up to an even number, so the canvas overhangs the screen by under two game pixels instead of showing bars. Even sizes avoid a 1 px edge gap from Phaser's pixel rounding.
- On wide screens UI groups stay centered (boat with bobber, Cast with the creel beside it, menu bar slots capped at 40 px, panels capped at 200x340) so nothing drifts to far edges.
- Progression is a journey of five waters with an opt-in fresh start (prestige). The boat tier that reaches the next water makes the move possible; moving resets coins, rods, boats, bait, and crew, and raises a permanent coin bonus set per water (`clubBonus`: +100%, +400%, +900%, +2400%). It never happens by surprise: the map asks twice and lists what starts over (no-punishment pillar). The journal, the daily gift, and the Club branch (cosmetics, `keepOnMove`) are kept.
- Waters the club has reached stay visitable for the journal; the bonus applies everywhere, so the newest water is about new fish and scenery, not a better payout per fish.
- Rods (luck), boats (creel space, quicker bites, reach), and bait (bigger fish that sell for more, a little luck) are chained tier nodes with `requiresRank`, so each water unlocks the next two tiers. The old Gear/Boat/Club tree became Rods, Boats, Bait, Crew, and Club.
- Lures are per-rarity weight boosts (`boost_<rarity>` stats, one per rarity, generated from `rarities.json`). They and bait apply to hand fishing only; crew get their own luck and sale upgrades, so offline math is unchanged. A tier's `maxChance` still caps the final chance.
- Club cosmetics are pure looks with no stats, since they survive every move.
- Costs were tuned with a whole-journey simulation (`tests/helpers/journeySim.ts`) rather than by hand: about 23, 39, 45, and 50 minutes per water, an 88 minute Sky Lake finale, about 4 hours in all for an active player.
- World save slice v2 adds `clubRank`. Older saves keep every water they had reached (rank from `knownUnlocked`), with that water's bonus, and keep their coins.
- Daily Catch keys on the player's own calendar day (like Wordle) and always uses the starting water, so every player, new or late game, fishes for the same fish. It draws from uncommon and rare fish that do not depend on weather, so it can be found in a few minutes. It pays 3x and has no streak.
- The share text is plain text with emoji squares (tier colors, a black square for a missed bite, a hook for today's fish), shared with the Web Share API on phones and the clipboard elsewhere. It never names the fish.
- Production builds register a small hand-written service worker (no new dependency): pages network first, other files cached first and refreshed in the background. Dev builds never register it.
- Settings scrolls (its rows are built then moved into a ScrollArea) so new rows never fall off short screens.
- Music is composed live with Web Audio (slow Cmaj7, Am7, Fmaj7, G6 pads, a soft bass, and a sparse pentatonic melody, with a generated reverb), so there is no audio file to license or download. Night is sparser with a music-box voice. A file in `MUSIC_FILES` replaces it. Effects and music have separate volumes, and music stops entirely at 0% or when muted.
- Every action has a sound, wired from bus events in one place. A sound repeated within 70 ms plays once, so selling a whole creel does not stack coin sounds. Disabled buttons give a soft two-note "not yet" rather than silence or an error buzz.
- Keeping fish now has a clear reason: selling kept fish together pays a bundle bonus (+5% per fish after the first, up to +50%). The catch card explains it for a player's first 25 catches, and when the creel is full.
- The tutorial never blocks play: bubbles hide while a panel or the catch card is open, tips that ask you to tap the world do not take taps, and tips pointing at the menu stay above the Cast row with a dotted line down. Saves from before the tutorial skip the guide but still get one-time tips.
- The Daily Catch share is now your first five catches of the day (any water) with a luck score (sum of tier + 1, 5 to 25), per playtester feedback. Today's fish still pays 3x and is marked with a hook when it is among the five.
- Feedback goes to a GitHub issue form (no backend). The game fills in the version and a short device summary (OS, browser, window size), never anything personal. Testers need a GitHub account. A Google Form or similar can replace it by changing `LINKS.feedbackUrl`.
- Text over the world uses a 1 px outline, and the top bar is a solid band, so coin values read on any sky.
- Hooked fish can slip away (playtest request). The chance grows with rarity and, steeply, with missing tackle (rods, boats, bait), so a legend without the right gear is a slim chance (12% to land), and with full gear about 85 to 95%. To keep it gentle: nothing is lost, the pity counter keeps counting, commons never slip, the message is kind and hints at tackle once it mattered, and crew and offline catches are unaffected.
- The fish is rolled when you cast, not when it bites, so the water can glow in the rarity's color while you wait (rare blue, epic purple, legendary gold). Rolling earlier changes nothing about the odds.
- Quick catch pays a coin bonus at once on landing (so it is not lost by keeping the fish): +25% within the first 35% of the bite window, +10% within 65%.
- Weather gained High Winds and Rainstorm, each with its own fish in every water, plus soft gusts, slanted rain, distant flashes (never a strobe, off with reduced motion), and wind and rain sounds. Bait and sails can make time- and weather-bound fish bite more (generated `boost_time_*` and `boost_weather_*` stats).
- Upgrade cards now list every requirement with a check or a lock (including "Club at <water>"), what the next level changes line by line, what it leads to, and how many more coins are needed.
- Water glints, stars, and painted streaks are fewer and dimmer (playtest: too stark), and glints move every 1.6 s instead of 0.7 s.
- Retuned after slip chances: Sturdy Skiff 800 (was 1000), Painted Rowboat 250, Hire Help 150, Whisper River bonus +200% (was +100%), so the first move still comes at about 20 minutes and rebuying gear after a move is about twice as fast. The pacing check for that is now "under 55% of the first run's time" (was 50%), since rare fish need tackle you have not rebought yet.
- Versions: small fixes and tuning are patch releases (0.3.1, 0.3.2). New systems or a big content drop raise the minor number (0.4.0). 1.0.0 is the public launch.
- Each water has landmarks and effects listed in data, and the club's own building gets grander with each move (shed, cabin, harbor, bungalows, grotto, domed clubhouse), so moving the club feels like moving up in the world. Approved by the owner from a screenshot review before release.
- Sunlit Reef is the sixth water (approved). The pacing test now checks every run before Sky Lake, not just the first four.
- Changing water plays a voyage: the full one for a club move, a 2 s one for a visit (owner's choice), and none with reduced motion.
- Crew fill only the creel while you are away (owner's request), so checking in and a bigger creel both pay. Live crew still sell, so active play is unchanged.
- Kept fish lose freshness only during play, with a 3 minute grace and a 60% floor, so keeping fish is a choice with a cost but never a loss. Crew catches arrive fresh when you return.
- Matching sets use only 3, 5, and 10 (owner's rule). A rarity earns its biggest set; 12 of a kind counts as a 10. Sets stack across rarities and sit on top of the bundle bonus.
- Gems are the second currency, kept on moves. They buy only looks (no stats). The coin price of a gem scales with the club bonus so late-game coins do not flood gems. Night Watch (away earnings) became the Ice Chest, since away coins no longer exist.
- Each water's sound and music are data (`sound` in `waters.json`); the night music box stays at every water so nights stay quiet.
- Crew base catch time is 30 s (was 12 s). 40 s pushed the journey past 6 hours because crew also sell while you play, so 30 s is the compromise.
- Fog is drawn as solid mist banks at partial opacity. Dithered full-screen fog read as a rendering bug.
- Boats are longer at each tier and carry the crew (owner's request); a boat's bunks cap how many crew can be hired, alongside Hire Help contracts. Bunks come at tiers 2, 5, and 8 so the first helper still arrives in the first run.
- Rare fish fight (owner's pick: a mix by rarity). A bad fight only raises the slip chance, it never loses the fish outright, and Easy reel turns fights off. A tap during the 280 ms after the hook or a dip is ignored so a double tap is not a fumble.
- Next for boats (owner's idea): boat styles and upgrades that change with each water, like the per-water sound and music.
- Guidance is two layers: a goal bar that always points along the journey (the main progression), and the Logbook for everything else the game wants to teach. Logbook tasks pay coins; only moving the club (and one Sky Lake task) pays gems, since gems are the premium currency (owner's direction).
- Upgrade tags are derived from stats in `config/focus.ts`, so new upgrades are tagged without extra data.
- Sign in and cloud saves are on hold until later (owner's call). Naming the club, boat, and crew and a favorite color are on the roadmap.
- No caps or cooldowns on play (owner's call). Return visits are rewarded instead: fresh bait from time away and three daily tasks.
- Keep for market replaces freshness (owner's pick): kept fish cannot sell for 2 minutes, which makes Sell (coins now) and Keep (more coins later with sets) a real choice. Two timers on one fish would feel like a penalty, so freshness was removed.
- Fish shadows never hint at the fish: plain, random shape and size (owner's rule). The rare glow at the bobber stays as a rarity hint.
- The legendary moment zooms the whole canvas with CSS rather than the Phaser camera, since a camera zoom resamples pixel art; its glow uses the legendary rarity color. Dimming the screen was tried and dropped (felt unrewarding).
- Later (owner's list): forecast, trader, weekly events, money ideas, and more polish (jumping fish, gulls, the cat walking, lanterns, a whale, rain ripples, line wobble, Logbook confetti, journal page flips).
- The fish shadow keeps the v0.8.0 glide (owner preferred it over the longer v0.8.1 path with a wake). How it reads on small phones is a later question, for example if the game becomes an app.
