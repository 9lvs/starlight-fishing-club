# Starlight Fishing Club

A calm pixel art fishing idle game for the web. Cast from a little boat under a
shifting sky, catch fish of gentle rarities, and grow your club.

## Run

```bash
npm install
npm run dev
```

Open the "Local" URL in a browser. To play on your phone on the same Wi-Fi,
open the "Network" URL that Vite prints (for example `http://192.168.1.20:5173`).
If your computer's firewall asks, allow incoming connections for Node.

URL flags: `?debug=1` shows the debug panel; `?debug=styleguide` opens the style guide.

## Test and build

```bash
npm test
npm run build
```

See `CLAUDE.md` for the project map and `docs/` for architecture and recipes.
